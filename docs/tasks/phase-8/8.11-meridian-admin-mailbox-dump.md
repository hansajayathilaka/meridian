# 8.11 — `meridian-admin mailbox dump <pubkey>`

**Phase:** 8 — Offline Ciphertext Mailbox · **Feature:** T07 · **Depends on:** 8.1, 8.2 · **Status:** pending

## Goal
Build the feature spec's "honesty demo" tool: make concrete, to an operator, exactly what threat
A7 can see about a mailbox — sizes, timestamps, opaque blobs, nothing else — rather than leaving
that claim as prose.

## Scope
- **In:** a new binary crate `apps/admin` (`meridian-admin`, added to the workspace `members` list)
  with a `mailbox dump <pubkey>` subcommand that opens the server's configured store (same
  `Store` trait/config as `meridian-rendezvous`, read-only access — no new store methods beyond
  8.1/8.2's `mailbox_list_for_recipient`) and prints, per row: size in bytes, `arrived_at`,
  `expires_at`, and the blob rendered as an opaque marker (e.g. `<opaque, N bytes>`) — never
  attempting to parse or display its contents.
- **Out:** no other `meridian-admin` subcommands beyond `mailbox dump` — do not scope-creep into a
  general admin CLI here; if other operator tooling is wanted later, that's a future task's job.
  No web/dashboard surface (T14's territory, deliberately deferred).

## Deliverables
1. `apps/admin` crate + `mailbox dump <pubkey>` subcommand.
2. A test (or the phase's demo script itself, if this project's convention is demo-as-test for CLI
   tools — check `apps/cli`'s own precedent) proving the tool never deserializes/decodes `blob`
   (reuse `tools/lint-no-serde-on-blob.sh`'s enforcement pattern, or an equivalent static check, for
   this new crate too).
3. Sample output matching the feature spec's demo script shape (`3 envelopes | 1.2 KiB, 0.9 KiB,
   4.1 KiB | ts … | contents: <opaque>`).

## Risks / notes
This tool exists specifically to make an honest claim concrete — resist any temptation to add a
"preview first N bytes" or similar convenience flag; the feature spec's own Risks/notes line says
"do not let convenience features creep in... the mailbox's entire security argument is its poverty
of function," and that applies as much to its inspection tooling as to the mailbox itself.

## Tests
`cargo nextest run -p meridian-admin`

## Reviews
- **security-reviewer** — confirms the tool's output is bounded to exactly what `data-model.md`
  already documents threat A7 as learning, no more.
- **devops** — CLI ergonomics, operator-facing output shape.
- **code-reviewer** — no-serde-on-blob discipline in the new crate.

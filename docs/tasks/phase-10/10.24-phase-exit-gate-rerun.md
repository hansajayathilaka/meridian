# 10.24 — Phase 10 exit-gate re-run

**Phase:** 10 — File Transfer Stream · **Feature:** T09 (fix) · **Depends on:** 10.19, 10.20, 10.21,
10.22, 10.23 · **Status:** pending

## Goal
Re-run task 10.17's own live acceptance demo, now that the `ice_restart` gap it found is fixed, and —
if it passes clean — actually close Phase 10's exit criteria (`docs/tasks/phase-10/README.md`,
`docs/tasks/README.md`'s ▶ NOW/NEXT). This is the task that either closes the phase or reports exactly
what still blocks it.

## Scope
- **In:** re-run the exact demo scenario from [10.17's transcript](./10.17-demo-transcript.md) Part 2
  (network cut + `ice_restart()` + resume, over real netns/veth, real WebRTC) end to end, including the
  spec's literal narration if `meridian send` itself has since gained wiring to drive this automatically
  (it doesn't, per 10.17's own finding — `send.rs` has zero auto-resume wiring, a separate,
  still-unowned carry-forward; if that's still true, continue using 10.15's dedicated driver exactly as
  10.17 did, and say so explicitly rather than treating it as newly in scope). Update
  `docs/tasks/README.md`'s ▶ NOW/NEXT and "Live carry-forwards" section and `docs/tasks/phase-10/README.md`'s
  Exit Criteria to reflect the actual outcome — closing the phase if the re-run is genuinely clean, or
  recording precisely what still blocks it if not (per the same Phase 4/7 "don't lower the bar"
  precedent 10.17 already established).
- **Out:** fixing anything new the re-run finds (that's a new task, per this phase's own established
  pattern of promoting a finding to its own owned fix rather than scope-creeping the task that found it).

## Deliverables
1. A new demo transcript (or an update appended to `10.17-demo-transcript.md`) recording the re-run's
   real output.
2. Tracker updates reflecting the actual outcome.

## Risks / notes
Don't declare the phase closed on partial evidence. If the re-run passes for the file-transfer scenario
but surfaces something new (e.g. a timing edge case only visible under a real cut), that's a fresh,
separately-scoped finding — name it, don't paper over it, exactly as every prior task this phase has
done.

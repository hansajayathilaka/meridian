only v2 envelopes, and the roadmap/tracker updated so T07 (mailbox) and T14 become pickable.

## Scope
- **In:** full-workspace build/lint/test gate; a live CLI two-party demo confirming only `v: 2`
  envelopes are on the wire; the roadmap/tracker doc updates that discharge the standing dependency
  gate this phase exists to satisfy.

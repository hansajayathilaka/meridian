# 2.11 — `demo/two-orgs/`: two full stacks, private CA, both discovery modes

**Phase:** 2 — Cross-Org Federation · **Feature:** T06 — Cross-Org Federation · **Depends on:** 2.4, 2.5, 2.7, 2.8 · **Status:** pending

## Goal
`cd demo/two-orgs && docker compose up` brings up `org-a.test` + `org-b.test` (rendezvous + coturn ×2),
a private CA, and no internet — the feature spec's working output, actually runnable.

## Scope
- **In:** `demo/two-orgs/` (a **new** directory — none exists today); the rendezvous Dockerfile;
  per-org configs; the static map plus a local DNS service so SRV mode is genuinely exercised; CA
  wiring; a scripted walkthrough; `just two-orgs` repointed.
- **Out:** the assertions themselves (2.12). This task delivers the stack and a runnable script;
  2.12 turns it into a gate.

## Deliverables
1. `demo/two-orgs/docker-compose.yml`, `Dockerfile.rendezvous`, `org-a.toml`, `org-b.toml`,
   `federation_map.toml`, `README.md`, `run-walkthrough.sh`.
2. A DNS service (dnsmasq or CoreDNS) serving `_meridian-fed._tcp.org-b.test` so the SRV mode is
   really tested, plus a compose profile/override for static mode.
3. `Justfile`: the `two-orgs` recipe replaced (it is currently a `TODO` echo stub).

  ([deployment.md](../../operations/deployment.md) §9.3).

# 4.13 — Extract shared account/home-layout helpers into `meridian-core`

**Phase:** 4 — Verification & Trust + Terminal TUI Client · **Feature:** T17 — Terminal TUI Client · **Depends on:** — · **Status:** done

## Goal
Close a gap the TUI design assumes but never states where to put: `tui-client.md` says the TUI "reads
the account descriptor and relay policy through the same code paths the CLI uses," but `config_dir()`,
`AccountDescriptor`, and `sessions_path()` currently live in `apps/cli/src/account.rs`. Since ADR 0020
makes `meridian-tui` depend on `meridian-core` only (never `meridian-cli`, to avoid a dependency cycle
given `meridian-cli` depends on `meridian-tui`), the TUI cannot reach that code as-is.

## Scope
- **In:** mechanical relocation of `config_dir()`, `AccountDescriptor`, `sessions_path()` (and any other
  `$MERIDIAN_HOME`-layout helpers the TUI's store/onboarding/unlock tasks need) from
  `apps/cli/src/account.rs` into `meridian-core`, with `apps/cli` re-exporting/using the relocated code
  so its own behavior is unchanged.
- **Out:** any behavior change — this is a relocation, not a redesign. New `tui/` subdirectory handling
  (4.15) builds on top of this but is a separate task.

## Deliverables
1. Relocated `config_dir()`/`AccountDescriptor`/`sessions_path()` in `meridian-core`.
2. `apps/cli/src/account.rs` updated to use the relocated code (no behavior change).
3. Test: existing CLI account tests still pass unchanged; a new `meridian-core` test exercises the
   relocated helpers directly.

## Risks / notes
- **Flagged architecture gap, not scope creep.** Nothing in `tui-client.md` says where this shared code
  should live; this task exists so `apps/tui`'s later tasks (4.14, 4.15, 4.17, 4.19) don't each
  improvise their own path to `$MERIDIAN_HOME`, which would fork the account-descriptor logic between
  CLI and TUI.
- Has no dependency on the ADR tasks or on T08 — can start immediately, in parallel with everything else.

## Tests
`cargo nextest run -p meridian-cli` · `cargo nextest run -p meridian-core`

## Reviews

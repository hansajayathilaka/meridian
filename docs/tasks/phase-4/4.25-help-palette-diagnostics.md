# 4.25 — Help overlay + command palette + diagnostics

**Phase:** 4 — Verification & Trust + Terminal TUI Client · **Feature:** T17 — Terminal TUI Client · **Depends on:** 4.18, 4.19, 4.20 · **Status:** pending

## Goal
Make the whole app discoverable without memorizing subcommands: `F1` help, `^K` fuzzy command palette,
a diagnostics view wrapping `doctor`, and the status bar.

## Scope
- **In:** help screen **generated from the binding table** (never hand-written, so a rebinding in
  `config.toml` can't go stale); palette listing every command with its binding, fuzzy-searchable;
  diagnostics view wrapping the existing `doctor` output plus live connection/transport/relay-policy
  state; status bar (connection state, transport path, relay policy).
- **Out:** the binding table itself (comes from 4.11's runtime + whatever screens have registered by
  this point, including 4.18's registry for feature-contributed palette commands).

## Deliverables
1. `apps/tui/src/screens/help.rs`, `palette.rs`, `diagnostics.rs`, status bar component.
2. Test: every binding in the table appears in both the generated help screen and the palette (no
   binding reachable only by memory).

## Tests
`cargo nextest run -p meridian-tui --test screens_help_palette`

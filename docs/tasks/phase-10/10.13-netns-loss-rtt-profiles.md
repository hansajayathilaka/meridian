# 10.13 — netns rig: loss/RTT injection profiles

**Phase:** 10 — File Transfer Stream · **Feature:** T09 · **Depends on:** — · **Status:** pending

## Goal
Extend the existing network-namespace test rig (`tools/netns-nat-matrix.sh`, from Phase 1's NAT-traversal
work) with `tc netem` loss/latency injection, so the soak and kill/resume tests (10.14/10.15) can run
under the feature spec's named profiles: 1% loss / 80 ms RTT.

## Scope
- **In:** a `tc netem` wrapper applied to the rig's veth interfaces, parameterized by loss % and RTT,
  reusable by any future test (not file-transfer-specific — pure test infra).
- **Out:** any file-transfer test logic itself (10.14/10.15 consume this).

## Deliverables
1. Loss/RTT injection added to the netns tooling (new script or an extension of
   `tools/netns-nat-matrix.sh`).
2. A smoke test proving the injected loss/RTT is actually observed (e.g. `ping` statistics under the
   profile match the configured parameters within tolerance).

## Risks / notes
This task has no dependency on any other Phase 10 task and can run in parallel with Wave 1 — it's pure
infra.

## Tests
The smoke test above, run manually or under whatever harness convention `tools/netns-nat-matrix.sh`
already follows (`--ignored` runner precedent from task 3.12, if this needs root/netns privileges CI
doesn't grant by default).

# 3.17 — Give the production stack a federation surface with a C7 guard-rail

**Phase:** 3 — Review of Phase 2 · **Feature:** review fix (F17) · **Depends on:** — · **Status:** done

## Goal
The doc that would otherwise *cause* an ADR 0017 C7 violation (Traefik-terminated 8444) must instead
prevent it.

## Scope
- **In:** a federation block (commented out is fine) in `infra/deploy/dokploy.compose.yml` publishing
  8444 as **raw TCP passthrough only**, plus `MERIDIAN_RENDEZVOUS_FEDERATION__*` plumbing in
  `dokploy.env.example`; a §6 warning in `docs/operations/docker-image.md` mirroring the demo compose
  header's ADR 0008-vs-C7 note.
- **Out:** any ADR — C7 already decides it. Also out: enabling federation by default.

## Deliverables
1. `infra/deploy/dokploy.compose.yml` + `infra/deploy/dokploy.env.example`.
2. `docs/operations/docker-image.md` §6 warning.

## Risks / notes
- Not a live violation today (federation defaults off/closed) — this is preventing a documented path
  into one. Keep that framing honest in the doc copy.
- The c2s plane **is** proxy-terminated by design (ADR 0008); only the s2s plane must not be. The
  warning must draw that distinction or it will read as contradicting §6's existing Traefik guidance.

## Tests
```
docker compose -f infra/deploy/dokploy.compose.yml config
bash tools/check-docs.sh
```

## Reviews
- **devops** · **security-reviewer** (C7 is a trust-boundary condition) · **architect**.

## Outcome
Added a commented-out (federation stays off by default) federation block to
`infra/deploy/dokploy.compose.yml`: a raw-TCP `8444:8444` port publish (no proxy/Traefik
annotations) plus the nine `MERIDIAN_RENDEZVOUS_FEDERATION__*` env vars, mirrored in
`dokploy.env.example`. Added a §6 warning in `docs/operations/docker-image.md` drawing the
ADR 0008 (c2s, proxy-terminated) vs. ADR 0017 C7 (s2s, must terminate in-process) distinction,
matching the wording precedent already in `demo/two-orgs/docker-compose.yml`'s header.

Reviews: security-reviewer + architect (combined pass) — both **pass**, no findings; verified all
env var names against `apps/rendezvous/src/config.rs`'s `Federation` struct, confirmed no
uncommented `ENABLED=true` path, confirmed the `0.0.0.0` bind override is justified and safe
(still gated by mTLS). devops — **pass**; verified `docker compose config` resolves cleanly with
the block commented (only 8443 published) and, in a scratch copy, with it fully uncommented (8444
+ all 9 vars resolve with sane defaults); one cosmetic wording nit applied.

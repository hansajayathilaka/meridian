## Goal
Land the five cheap, disjoint-file nits from Phase 5's review report in one bundled task, mirroring
Phase 3's task 3.21 precedent for bundling small doc/comment nits — none warrants its own reviewer round
trip on its own.

## Scope
- **In:**
  - **N2** — `docs/architecture/features/17-terminal-tui-client.md:102,104`: `^N`/`^V` → `n`/`v` (the
    real bindings; flagged and left unfixed across three prior sweeps in Phase 4).
  - **N3** — `apps/core/src/trust.rs:430-434`: `observe_key_change`'s `ConflictingContact` guard is
    tautological given the module's own invariant (`contacts[k].pubkey == k` always holds, and the
    early-return above already guarantees `new_pubkey != previous_pubkey`). Simplify to a flat
    `contains_key` check with a comment explaining the invariant, or add a `debug_assert`. Behavior-
    preserving only.
  - **N4** — `apps/tui/src/screens/diagnostics.rs:89-92`: close the `run_doctor_binary` `PATH`-resolution
    `TODO: confirm` inline — the module's own doc comment already states the accepted-risk rationale
    (no new trust boundary beyond the shell already trusted to launch `meridian tui`); replace the hedge
    with a stated, closed decision rather than opening a separate task for it.
  - **N5** — `docs/adr/README.md:31`: front-load ADR 0022's "Superseded by 0023" note in its summary-
    table cell instead of trailing it.
  - **N6** — `apps/tui/src/surface.rs:232-238`: add a doc comment distinguishing `PaletteAction::PushScreen`
    (built-in `Screen` variants only) from `PushPane` (the real sanctioned third-party extension point).
- **Out:** N1 (own task, 5.11 — structural extraction in security-adjacent code) and N7 (own task, 5.12
  — a genuine policy decision, not a doc nit) are deliberately **not** in this sweep.

## Status
**Done** — tooling added *and* the unmeasurable figure dropped, because measuring it revealed the
figure was impossible in a second, sharper sense than the report knew.

### The finding
The criterion said "**≥90% branch coverage**". The report treated it as unverifiable because the
project had no coverage tooling. Installing the tooling showed something stronger: **Rust on stable
emits no branch-coverage data at all** — `cargo llvm-cov`'s Branches column is `0 / 0 / -` on the
toolchain `rust-toolchain.toml` pins. Branch coverage needs a nightly `-Z coverage-options=branch`
build. The metric was unachievable regardless of effort, so adding tooling alone would not have made
the criterion true — the wording had to change too.

### Landed
- `Justfile`: `just coverage` (`--summary-only`) and `just coverage-html`, with the stable/branch
  caveat in a comment; `setup` now names the two install steps.
- `.github/workflows/ci.yml`: a `coverage` job — **measurement only**, `continue-on-error: true`, no
  threshold, uploads an lcov artifact. Per this task's Risks note, gating is explicitly *not* decided
  here.
- `docs/architecture/features/01-identity-keystore-core.md`: deliverable 1's "≥90% branch coverage"
  replaced with "well-covered … — measured, see Coverage below", plus a "Coverage (F22 / task 1.21)"
  section carrying the caveat and the real numbers.
